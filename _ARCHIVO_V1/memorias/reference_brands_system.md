Todos los perfiles de marca del portafolio ZAINT viven en:

`C:\DEPARTAMENTO MODOZAINT\BRANDS\`

## Archivos

- `BRANDS/DERMATINTA.md` — Identidad completa: tokens de color (#0D3D34 verde, #C49A52 dorado, #FBF8F1 crema), tipografía (Georgia/Cormorant + DM Sans), prompts de imagen listos para Midjourney/Ideogram/Leonardo, tono y CSS de producción.
- `BRANDS/HOUSE_OF_KAIZEN.md` — Identidad parcial: tono y buyer personas definidos, paleta/tipografía PENDIENTE.
- `BRANDS/MODOZAINT.md` — Identidad parcial: tono y formato definidos, paleta/tipografía PENDIENTE.
- `BRANDS/_TEMPLATE.md` — Template para crear perfiles de nuevas marcas.
- `BRANDS/README.md` — Índice + guía de herramientas de imagen recomendadas + regla de no-mezcla.

## Cómo aplicar

Antes de crear cualquier pieza visual para una marca: leer su archivo en BRANDS/, copiar el prompt de imagen de la sección 5, usar la herramienta apropiada (fotos reales → producto, Midjourney/Leonardo → lifestyle AI, Ideogram → banners con texto, Canva → assets gráficos).

**Why:** [[feedback-proactive-vault-writing]] + necesidad de consistencia visual entre sesiones.
**How to apply:** Siempre que el usuario pida imágenes, diseño o contenido para una marca, leer primero su BRANDS/[MARCA].md.
