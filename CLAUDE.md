# MODOZAINT V2 - entrada unica

> Esta carpeta es la casa nueva para trabajar MODOZAINT sin tocar el V1.
> El V1 sigue vivo en C:\DEPARTAMENTO MODOZAINT mientras la migracion se hace por piezas.

## Que es y que no

- Es el espacio de trabajo nuevo.
- No es una copia del V1.
- No migra operacion por accidente.

## Ciclo

`00_NORTE -> 10_ESTRATEGIA -> 20_OPERACION -> 30_RESULTADOS -> 40_APRENDIZAJE -> 50_SOP -> 60_CONOCIMIENTO -> 70_AGENTES -> _ARCHIVO_V1`

## Como se trabaja

- Capacidad finita: si entra algo nuevo, sale de algun lado.
- Foco: maximo 2 cuentas activas.
- Entregado = publicado o en manos de quien paga.
- Nada se mueve; si algo se trae del V1, se copia.

## Lo que frena

- Las cuatro protecciones del sistema.
- Si algo no esta en `SISTEMA/PROTECCIONES.md`, no inventes frenos nuevos.
