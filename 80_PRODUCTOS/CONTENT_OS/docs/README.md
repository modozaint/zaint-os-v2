# Content OS

Sistema de inteligencia de contenido para tu marca personal, construido con Claude Code.

Conecta tus redes sociales, transcribe y analiza tu contenido con IA, y chatea con un agente que conoce todo tu historial.

## Qué necesitás

- Node.js — [nodejs.org](https://nodejs.org) (versión LTS)
- Claude Code — `npm install -g @anthropic/claude-code`
- Cuenta en [claude.ai](https://claude.ai) con plan Pro o Max

## Cómo arrancar

1. Abrí la terminal
2. `cd ruta/a/content-os-plantilla`
3. `claude`
4. `/iniciar`

Claude te guía el resto.
